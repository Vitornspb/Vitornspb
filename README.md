### 👨‍💻 Sobre mim

Atuo com **engenharia e análise de dados**, desenvolvendo soluções para integração, tratamento, validação e automação de dados provenientes de diferentes sistemas.

Tenho experiência com **Python, SQL, APIs REST, pipelines de dados, ETL/ELT e automação de processos**, com foco em qualidade, confiabilidade e eficiência dos dados.
